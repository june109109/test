# 9-6. 프로파일링 도구 선택 — 정답·해설

[본문](06-profiling.md) · [목차](../README.md)

## Q1 — 1점

아닙니다. 추적하는 할당 범위와 프로세스 전체 상주 메모리의 정의가 다릅니다.

## Q2 — 1점

아닙니다. 의도한 유지/peak인지 작업 종료 후에도 불필요한 참조가 누적되는지 봐야 합니다.

## Q3 — 2점

py-spy는 실행 stack/시간 분포의 샘플(1점), tracemalloc은 추적 Python 할당의 위치·변화(1점)입니다.

## Q4 — 2점

각 1점: native 확장 할당, allocator 보유/fragmentation, mmap, 공유 페이지/자식 프로세스 등 두 가지.

## Q5 — 4점

각 1점: 동일 반복과 안정화/대조군, 여러 snapshot·RSS/cgroup 병행, 참조 유지/native 범위의 가설, 수정 후 같은 부하·오버헤드 고려 재검증. 한 snapshot만으로 누수라 단정하지 않습니다.

8점 미만이면 틀린 질문과 관련된 본문을 복습하고, 조건을 하나 바꿨을 때 답이 달라지는 이유를 적으세요. 서술형은 제품 이름보다 제약·근거·비용·검증 방법을 평가합니다.
