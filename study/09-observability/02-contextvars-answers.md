# 9-2. contextvars와 실행 경계 — 정답·해설

[본문](02-contextvars.md) · [목차](../README.md)

## Q1 — 1점

일반적으로 안 됩니다. 여러 task가 같은 스레드에서 실행될 수 있습니다.

## Q2 — 1점

아닙니다. 해당 token이 가리키는 이전 값을 복원합니다.

## Q3 — 2점

기본 task 생성 시 context를 복사하기 때문(1점), 이후 변경을 공유하는 전역 셀이나 mutable 값의 깊은 복사와는 다름(1점)입니다.

## Q4 — 2점

실험의 to_thread에는 요청 ID가 전달되었습니다(1점). 기본 run_in_executor에서는 default null이었으며 자동 전파를 가정하지 않습니다(1점).

## Q5 — 4점

각 1점: 진입점 set/finally reset, task 생성 시점·background 수명, HTTP/큐의 명시적 전파, 외부 ID/인증 정보의 신뢰·job ID 구분. ContextVar만으로 네트워크 전파된다고 하면 안 됩니다.

8점 미만이면 틀린 질문과 관련된 본문을 복습하고, 조건을 하나 바꿨을 때 답이 달라지는 이유를 적으세요. 서술형은 제품 이름보다 제약·근거·비용·검증 방법을 평가합니다.
