# 6-6. 로그인 흐름 검증 실습 — 정답·해설

[본문](06-login-lab.md) · [목차](../README.md)

## Q1 — 1점

아닙니다. 로컬 테스트 제공자와 client의 제한된 계약을 검증한 것입니다.

## Q2 — 1점

아닙니다. ASGITransport 내부 호출이며 browser ID는 바인딩 시험용 값입니다.

## Q3 — 2점

고정 키는 알려진 한 키로 서명을 확인(1점), JWKS 회전은 신뢰한 키 출처·kid·캐시·새/이전 키·조회 실패까지 다룹니다(1점).

## Q4 — 2점

로그인 시도가 시작된 브라우저/세션과 callback을 연결하는 조건입니다(1점). 저장소에 state가 존재한다는 사실만으로 다른 브라우저에 적용하지 않도록 합니다(1점).

## Q5 — 4점

각 1점: 실제 제공자 설정/인가·교환, 브라우저 HTTPS/cookie/CSRF, 여러 워커의 원자적 시도 소비, 키 회전/refresh/장애와 로그 보호 중 네 영역. 제품명만 나열하지 않고 실패 조건을 적습니다.

8점 미만이면 틀린 질문과 관련된 본문을 복습하고, 조건을 하나 바꿨을 때 답이 달라지는 이유를 적으세요. 서술형은 제품 이름보다 제약·근거·비용·검증 방법을 평가합니다.
