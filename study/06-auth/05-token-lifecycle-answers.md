# 6-5. 토큰 수명과 계정 연결 — 정답·해설

[본문](05-token-lifecycle.md) · [목차](../README.md)

## Q1 — 1점

아닙니다. 서비스 세션·제공자 로그인·API 위임 토큰은 별도의 수명과 철회 정책을 가집니다.

## Q2 — 1점

안 됩니다. 이메일 변경·재할당·제공자 정책 차이가 있고 기존 계정 소유를 증명하지 않습니다.

## Q3 — 2점

탈취 후 사용 가능 시간 감소(1점), 갱신/재인증과 실패 처리 증가(1점)입니다.

## Q4 — 2점

정상 워커 둘이 같은 이전 refresh token을 사용해 재사용 탐지를 유발할 수 있습니다(1점). single-flight·원자적 버전 갱신·명시적 실패 처리가 필요합니다(1점).

## Q5 — 4점

각 1점: 기존 계정 인증/필요시 재인증, 외부 OIDC 검증과 issuer+sub, 이미 연결된 신원의 유일성·원자적 저장, 해제 후 남는 로그인 수단과 토큰 폐기. 이메일만으로 연결하면 핵심 요건을 충족하지 못합니다.

8점 미만이면 틀린 질문과 관련된 본문을 복습하고, 조건을 하나 바꿨을 때 답이 달라지는 이유를 적으세요. 서술형은 제품 이름보다 제약·근거·비용·검증 방법을 평가합니다.
