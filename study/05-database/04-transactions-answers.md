# 5-4. 트랜잭션과 ACID — 정답·해설

[본문](04-transactions.md) · [목차](../README.md)

## Q1 — 1점

아닙니다. 외부 시스템은 DB transaction의 원자적 경계 밖에 있습니다.

## Q2 — 1점

아닙니다. commit이 성공하고 응답만 유실되었을 수 있으므로 상태 조회·멱등 키가 필요합니다.

## Q3 — 2점

Consistency는 제약·불변식 유지(1점), isolation은 동시 transaction의 관찰·충돌 규칙(1점)입니다. ACID라는 이름만으로 모든 업무 규칙이 자동 보장되지는 않습니다.

## Q4 — 2점

각 1점: 연결 점유로 풀 대기 증가, 락 점유로 다른 작업 지연, 오래된 MVCC 버전 정리 지연, 외부 장애의 DB 전파 중 두 가지.

## Q5 — 4점

각 1점: 요청별 안정된 멱등 키/유일성, 불명확 상태를 실패로 단정하지 않는 상태 모델, 제공자 조회와 제한된 재시도, 성공 반영·환불/수동 복구 경로. 매번 새 멱등 키로 무제한 재결제하면 안 됩니다.

8점 미만이면 틀린 질문과 관련된 본문을 복습하고, 조건을 하나 바꿨을 때 답이 달라지는 이유를 적으세요. 서술형은 제품 이름보다 제약·근거·비용·검증 방법을 평가합니다.
