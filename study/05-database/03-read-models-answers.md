# 5-3. 역정규화와 읽기 모델 — 정답·해설

[본문](03-read-models.md) · [목차](../README.md)

## Q1 — 1점

아닙니다. 일반 뷰와 materialized view를 구분해야 합니다.

## Q2 — 1점

다릅니다. 배송/계약 당시 주소는 시점이 있는 별도 사실이며 현재 주소 변경으로 덮어쓰지 않아야 할 수 있습니다.

## Q3 — 2점

각 1점: 재전달·재시도, 버전/중복 처리, 지연·누락 탐지, 원본에서 재구축 중 두 가지. 단순 로그만으로 복구된 것은 아닙니다.

## Q4 — 2점

발행 성공과 확인 기록 사이의 장애로 같은 이벤트를 다시 전달할 수 있습니다(1점). 중복 효과를 막도록 event_id·유일 제약·조건부 갱신 등을 설계합니다(1점).

## Q5 — 4점

각 1점: 결제 원본 직접 조회 경로, 검색의 비동기 반영 경로, 지연/실패 관측과 재처리, 사용자 경험과 버전·중복 처리. 모든 값을 하나의 캐시에서 읽는 답은 최신성 보장을 설명해야 합니다.

8점 미만이면 틀린 질문과 관련된 본문을 복습하고, 조건을 하나 바꿨을 때 답이 달라지는 이유를 적으세요. 서술형은 제품 이름보다 제약·근거·비용·검증 방법을 평가합니다.
