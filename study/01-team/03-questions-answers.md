# 1-3. 정답과 해설

[본문](03-questions.md)

## Q1 — B, 1점

파괴적 작업의 의미가 불명확하면 실행을 중단하고 확인해야 합니다. ‘소량’도 실제 고객 삭제라면 무해한 실험이 아닙니다. 질문 전 탐색의 목적은 위험을 낮추는 것이지 질문 자격을 증명하는 것이 아닙니다. 복습: 1절.

## Q2 — 응답 시점의 선택권과 지연, 1점

장점은 답변자가 적절한 시점에 응답하고 기록을 재사용할 수 있다는 점입니다. 비용은 첫 응답 지연과 맥락 부족에 따른 왕복입니다. 둘 다 설명하면 1점. 비동기 채널을 썼다고 알림에 따른 중단이 저절로 없어지지는 않습니다. 복습: 2절.

## Q3 — 재현·기대·환경·영향, 2점

다음 중 네 항목을 구체화하면 2점, 두세 항목이면 1점입니다: 기대/실제 결과, 오류 메시지·최소 재현, Python·라이브러리 버전, 실행 명령, 확인한 문서·시도 결과, 무엇이 언제까지 막히는지, 원하는 답의 범위. 비밀값이 포함된 전체 로그를 그대로 요구하지 않습니다. 복습: 4절.

## Q4 — 구조적 원인과 대응, 2점

각 원인과 대응을 연결하면 1점씩입니다. 예: 검색되지 않는 문서는 목차·검색 키워드·링크를 개선합니다. 암묵적인 도메인 규칙은 예시·결정 배경을 기록합니다. 초기 안내가 없으면 작은 온보딩 실습을 제공합니다. 특정 담당자만 아는 구조라면 페어 작업과 문서 검토로 지식을 분산합니다. 복습: 3절 C, 5절.

## Q5 — 상호 비용을 다루는 규칙, 4점

예시: 일반 질문은 공개 채널의 양식으로 모으고 담당 당번이 작업 중간의 정해진 확인 시간에 우선순위를 매긴다. 장애·파괴적 작업 불확실성은 즉시 지정된 긴급 경로로 알리고 해당 작업을 중단한다. 숙련자의 집중 시간은 공개하고, 응답이 불가능할 때의 대체 담당자를 둔다. 반복 질문은 상담 시간에 묶어 풀고 해결 내용을 담당 문서에 반영한다. 당번도 모르는 내용은 추측하지 말고 필요한 사람에게 연결한다.

| 1점씩 | 조건 |
| --- | --- |
| 위험 구분 | 일반과 긴급을 실제 영향으로 구분 |
| 중단 관리 | 집중 시간과 예측 가능한 확인 시점을 모두 제공 |
| 책임 | 당번·대체자·상향 경로 등 질문이 방치되지 않는 구조 |
| 축적 | 해결 기록·문서 개선·반복 원인 확인 |

‘매번 즉답’과 ‘질문은 퇴근 전에만’은 한쪽 비용만 줄입니다. 응답 횟수나 질문 횟수를 개인 성과 점수로 만들면 질문 은폐·성급한 답변을 유발할 수 있습니다. 복습: 2~5절.
