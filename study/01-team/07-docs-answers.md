# 1-7. 정답과 해설

[본문](07-docs.md)

## Q1 — 참조 문서, 1점

정확한 옵션·단위·기본값을 찾는 질문입니다. 배경 설명이나 시작 튜토리얼이 추가로 도움이 될 수 있지만 빠르게 찾을 참조가 우선입니다. 복습: 2절.

## Q2 — 불필요하지 않다, 1점

생성 문서는 스키마와 구조를 반영하지만 금액의 통화·권한·호환성·실제 비즈니스 의미까지 자동 보증하지 않습니다. 코드와 문서가 함께 잘못될 수도 있습니다. 복습: 4절.

## Q3 — 중복을 줄이고 실행·계약 확인, 2점

권위 있는 명세로 링크하거나 필요한 부분을 자동으로 가져오는 방법에 1점, 튜토리얼 예제가 현재 계약에서 실제로 동작하는지 확인하는 절차에 1점입니다. 날짜만 고치는 것은 검증이 아닙니다. 복습: 4~5절.

## Q4 — 독자에게 보이는 변화, 2점

적절한 기준 하나당 1점입니다. 예: 공개 계약·예외·기본값 변경, 설치·테스트·배포 절차 변경, 데이터 의미 변경, 운영 대응 변경, 설계 결정을 바꾼 근거. 내부 구현 정리만으로 사용자 행동이 같다면 별도 문서 변경이 불필요할 수 있습니다. 복습: 3절 C.

## Q5 — 원본·독자·갱신 경로, 4점

예시: 신규 사용자는 작동하는 최소 튜토리얼을 읽고 상세 필드는 생성 명세로 이동한다. 기존 사용자는 버전별 계약·변경 내역으로 호환성을 확인한다. 운영자는 별도 runbook을 사용한다. 구조적 계약은 선택한 코드 스키마 또는 명세 파일에서 관리하고 비즈니스 의미는 해당 항목에 연결한다. PR에서 명세 차이와 대표 요청·응답 예제를 검증한다. 구버전 문서는 대상 버전을 표시하고 현재 문서에서 혼동되지 않게 분리한다.

채점: 독자별 경로 1점, 정보별 원본과 중복 방지 1점, 변경 검증 1점, 구버전·삭제·소유 책임 1점. 코드 우선과 명세 우선 중 특정 방식이 정답인 것은 아닙니다. 복습: 2·4·5절.
