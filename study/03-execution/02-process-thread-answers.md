# 3-2. 정답과 해설

[본문](02-process-thread.md)

## Q1 — 아니다, 1점

주소 공간이 분리되어 있습니다. 명시적인 IPC·공유 메모리·외부 저장소가 필요합니다. 프로세스 생성 시 데이터가 복제되는 것과 이후 변경이 공유되는 것도 다릅니다. 복습: 1절.

## Q2 — 아니다, 1점

커널 모드 진입과 다른 실행 흐름으로의 스케줄링은 구별됩니다. 곧바로 완료되는 시스템 호출도 있습니다. 복습: 2절.

## Q3 — 복합 업무 연산은 별도 보호, 2점

읽기·검사·갱신 사이에 다른 실행이 끼어들 수 있다는 설명 1점. 같은 불변 조건 전체에 대한 락, 단일 소유자 메시지 처리, 적절한 DB 트랜잭션 등의 대안 1점. 복습: 3절.

## Q4 — 전달·초기화·자원 비용, 2점

직렬화/역직렬화·복사, 프로세스 시작·라이브러리 로드, 메모리 대역폭 경쟁, 작은 작업의 스케줄링 비용, CPU quota 등을 두 개 제시하면 각 1점입니다. 병렬이라는 이름만으로 총시간이 줄지는 않습니다. 복습: 4절.

## Q5 — 선택보다 관리 조건, 4점

예시: SDK의 스레드 안전 조건을 확인하고 제한된 스레드풀을 사용한다. 공유 상태 갱신은 단일 소유자에게 메시지로 보내거나 필요한 임계 구역을 락으로 보호한다. 대기 큐·예외·종료 시 미완료 작업을 정의한다. 전환·락 대기·메모리·하류 한도를 관찰한다. 프로세스를 택해도 공유해야 할 상태의 외부화와 전달 비용을 설명하면 타당합니다.

채점: 공유 범위 1점, 동기화·소유 1점, 실패·종료 1점, 비용·대안 1점. 복습: 3~4절.
