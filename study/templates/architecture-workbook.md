# 포털 메인 설계 워크북

[12장 리뷰](../12-architecture/06-design-review.md) · [목차](../README.md)

실제 네이버 구조를 추측하는 문서가 아닙니다. 가상 서비스의 가정·선택·검증을 기록하세요. 빈칸을 채운 뒤 퀴즈와 별도로 동료 리뷰를 받습니다.

## 1. 범위와 목표

- 핵심 사용자 행동 / 제외 기능:
- 성공·오류·신선도의 정의와 측정창:
- 공개 / 개인화 / 어드민의 SLO:
- 운영 인원·예산·지역·보관 제약:

## 3. 데이터와 경계

- 읽기 경로 그림:
- 변경/전달/검색/무효화 경로 그림:

- 세션/권한/긴급삭제의 별도 조건:

## 4. 실행 자원

CPU시간, 스레드 점유, DB 점유, 실제 동시 SDK한도, 전체 연결 예산을 각각 계산합니다. 배포·자동확장 최대치와 발생기 한계를 포함합니다.

## 6. 두 대안과 ADR

- 안A / 안B:

## 7. 검증 계획

부하 모델·데이터·warmup·측정시간·반복·지표·중단기준·정리를 적습니다. 이미 실행한 것과 앞으로 할 것을 구분합니다.
