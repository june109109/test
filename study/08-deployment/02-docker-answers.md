# 8-2. Docker 이미지 만들기 — 정답·해설

[본문](02-docker.md) · [목차](../README.md)

## Q1 — 1점

아닙니다. 태그는 재지정될 수 있으므로 digest와 실제 배포 버전을 기록합니다.

## Q2 — 1점

아닙니다. 필요한 라이브러리의 취약점과 패치·런타임 권한은 별도로 관리합니다.

## Q3 — 2점

코드만 바뀔 때 의존성 설치 레이어를 재사용할 수 있습니다(1점). 실제 lock과 build context가 같아야 하며 무조건 재현성을 보장하지는 않습니다(1점).

## Q4 — 2점

이전 레이어에 값이 남을 수 있습니다(1점). secret mount/런타임 제공 경로를 사용해야 합니다(1점).

## Q5 — 4점

각 1점: base/의존성·hash 고정, ABI/플랫폼·런타임 라이브러리, non-root·쓰기 경로·secret 분리, 실제 시작/health/요청/종료와 digest 기록. 템플릿을 실행했다고 주장하면 안 됩니다.

8점 미만이면 틀린 질문과 관련된 본문을 복습하고, 조건을 하나 바꿨을 때 답이 달라지는 이유를 적으세요. 서술형은 제품 이름보다 제약·근거·비용·검증 방법을 평가합니다.
