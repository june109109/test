# 8-3. 컨테이너 자원과 워커 수 — 정답·해설

[본문](03-resources.md) · [목차](../README.md)

## Q1 — 1점

아닙니다. 기간당 CPU 시간 예산이며 독점·간섭 없음까지 보장하지 않습니다.

## Q2 — 1점

안 됩니다. quota·affinity·런타임 버전·작업 특성·메모리·하류 한도를 확인해야 합니다.

## Q3 — 2점

affinity/cpuset은 실행 가능한 CPU 집합(1점), quota는 사용할 CPU 시간 상한(1점)입니다.

## Q4 — 2점

각 1점: 힙/캐시 메모리, DB/HTTP 풀, 스케줄링, 시작 시간 등 두 가지.

## Q5 — 4점

각 1점: 같은 부하/제한에서 워커 한 변수 변경, CPU 사용·throttling, p95/p99·오류·처리량, 메모리 피크·하류 풀·배포 공존. 경험칙만으로 확정하지 않습니다.

8점 미만이면 틀린 질문과 관련된 본문을 복습하고, 조건을 하나 바꿨을 때 답이 달라지는 이유를 적으세요. 서술형은 제품 이름보다 제약·근거·비용·검증 방법을 평가합니다.
