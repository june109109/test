# 8-1. 리버스 프록시와 앱 서버 — 정답·해설

[본문](01-proxy.md) · [목차](../README.md)

## Q1 — 1점

리버스는 서버 측 진입점을, forward는 클라이언트의 외부 접속을 대리합니다.

## Q2 — 1점

아닙니다. 실제 설정·용량·TLS·보안·가용성·앱 병목을 각각 설계해야 합니다.

## Q3 — 2점

각 1점: client IP 조작, scheme/redirect 오류, host 기반 URL/정책 오염 등. 신뢰할 프록시 경로와 직접 접근 통제가 필요합니다.

## Q4 — 2점

느린 클라이언트와 앱의 점유 분리(1점), 버퍼 비용·전송 지연·SSE 즉시성 문제(1점)입니다.

## Q5 — 4점

각 1점: 필요한 앞단 기능, 불필요한 중복 홉의 비용, 프록시→앱 접근 제한/헤더 신뢰, 경로별 timeout·streaming·관측. nginx 유무 자체는 정답 기준이 아닙니다.

8점 미만이면 틀린 질문과 관련된 본문을 복습하고, 조건을 하나 바꿨을 때 답이 달라지는 이유를 적으세요. 서술형은 제품 이름보다 제약·근거·비용·검증 방법을 평가합니다.
